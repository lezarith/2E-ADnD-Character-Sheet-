   This is a fillable character sheet that is a heavily modified copy of the one @https://github.com/tamas-rabel/tamas-rabel.github.io.
It features automated ability score modifier tracking, encumbrance tracking, spell slot tracking, THAC0, MTHAC0, Saves. A lot.

https://lezarith.github.io/2E-ADnD-Character-Sheet-/

   My House Rules ON mode Tracks Your character level as Dual-Class or Multi-Class depending on you character levels. 
You can toggle House Rules to Off, and the character sheet you save and load should keep that stored. Doing that should make the HP behave more or less RAW, with the exception of using max hp at level 1, and averaging the roll afterwards.

Entering HP manually should also disable the auto-calculator, in case you'd rather generate HP some other way. You can always toggle HP between auto/manual at any time.

   My house rule is basically you can choose to start as a multi-class character or a single-class character. Multi-class characters use one unified xp pool that is all xp requirements added up, with all classes advancing at the same time.
    Single-class character advance as normal, but if they choose to dual-class they have to level that class until they become the same level, at which point they become a multi-class character. I personally don't allow for a character to level any new classes until their two, three classes are all at the same level.
Its up to you if you want to allow character to level dip how they want, and the auto-hp calculator shouldn't break if they do.

   Characters can only have one class of each class group. I.e. Warriors, Rogues, etc., at the moment. 

   I also use The Way Revised as my table's psionic rules which can be found here: https://drive.google.com/file/d/1WrrKKe-Y4Qhgjnd3tXzccvK_-hikQuf7/view?usp=sharing

   Skills and Powers Psionics is kinda baked in, but you're free to ignore the MTHAC0 portion, and the house rules turned off should let you fill in the max PSP manually.
Feel free to completely ignore the Psionics section, altogether. I placed it at the bottom for just that purpose ;)
